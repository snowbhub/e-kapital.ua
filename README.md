# єКапітал

**Навігатор особистого капіталу** — український local-first фінансовий планувальник.

Railway-домен (стан розгортання перевіряється в Railway): https://e-kapital-production.up.railway.app  
Особистий кабінет: https://e-kapital-production.up.railway.app/app

## Що працює

- Старт без реєстрації: порожній профіль, введення доходів, витрат, резерву та капіталу.
- Доходи в різних валютах і з різною частотою, категорії витрат, борги, вільний cash flow, власний місячний розподіл на 100%, фактичний check-in.
- Резерв за обов’язковими витратами й борговими платежами; цілі з базовим шляхом без дохідності та окремим власним сценарієм.
- Portfolio Lab: 11 класів активів, відсотки / суми, фіксація часток, зміна порядку, збережені сценарії, окремі номінальна та реальна вартості, виплати й внески.
- Ручний облік активів, зобов’язань, операцій і датованих знімків чистого капіталу.
- Калькулятори ОВДП з XIRR, депозиту, металів, накопичення, інфляції, фінансової свободи та двоетапної іпотеки єОселя.
- Публічні інформаційні сторінки, FAQ, SEO, sitemap, JSON-LD, каталог провайдерів та стан офіційних джерел.
- IndexedDB, встановлювана PWA, офлайн-оболонка, AES-GCM backup, перевірка імпорту та підтверджене видалення даних.

Особисті фінансові дані не передаються на сервер. `/api/market` та `/api/history` містять тільки публічні дані.

## Запуск

Node.js 24 рекомендовано.

```sh
npm ci
npm run dev
```

Production:

```sh
SITE_URL=https://your-domain.example npm run build
npm start
```

Перевірки:

```sh
npm run lint
npm run typecheck
npm test
npm run build
npx playwright install --with-deps chromium firefox webkit
npm run test:e2e
```

Playwright містить desktop Chrome, Firefox, Safari, iPhone Safari та Android Chrome. Для середовища з обмеженим доступом до browser CDN доступний `BUNDLED_CHROMIUM=true`; це перевіряє тільки Chromium desktop / mobile і не замінює Safari / Firefox.

## Дані та розгортання

```sh
npm run data:sync
```

GitHub Actions щодня перевіряє офіційні джерела, зберігає останні валідні значення при помилці та сигналізує про недоступні джерела. Railway збирає Dockerfile та отримує оновлення гілки `main`.
