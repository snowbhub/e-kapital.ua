# Архітектура

## Застосунок

Next.js App Router, React, TypeScript strict, Tailwind 4 та локальні стилі. Публічні сторінки мають SSR / статичний HTML для SEO; особистий кабінет позначено noindex. Невеликі SVG-графіки не потребують важкої chart-бібліотеки.

`src/components` містить модулі UI. `src/lib/finance` — чисті фінансові функції. `src/lib/storage` — Zod-схема профілю, IndexedDB, місячний rollover та Web Crypto. `src/lib/data` — провайдери, валідація й агрегація офіційних даних.

## Особисті дані

Одна версійована структура `State` в IndexedDB `e-kapital`, object store `state`, ключ `profile`. Зміни зберігаються із затримкою 250 мс і послідовною чергою записів. Статус збереження видимий. Новий місяць створюється без автоматичного копіювання доходів; попередні місяці залишаються. Перенесення регулярних рядків виконується явною дією.

Backup: PBKDF2-SHA256 (310000 ітерацій), випадкова сіль 16 байтів, AES-GCM-256, випадковий IV 12 байтів. Пароль мінімум 10 символів. Після дешифрування перевіряється вся Zod-схема. Заміна профілю потребує підтвердження.

Посилання сценарію містить лише дозволені гіпотетичні параметри в URL fragment. Доходи, фактичні активи, журнал та цілі не додаються. Preview показує параметри до поширення.

## Сервер

Сервер не має бази особистих профілів. Він віддає публічні snapshots і намагається оновити курси НБУ з денним кешуванням. Немає входу в банки, акаунтів, AI-прогнозів, платежів або аналітики. Секрети для запуску не потрібні.

HTTP healthcheck: `/api/health`. Docker standalone, non-root користувач. CSP, HSTS, X-Content-Type-Options, Referrer-Policy та обмеження Permissions-Policy налаштовані в `next.config.ts`. Inline scripts дозволені для Next.js hydration / JSON-LD; це свідоме обмеження поточної CSP.

Service worker кешує app shell, статичні ресурси та публічний market snapshot. Особистий профіль не записується в HTTP cache. Версія кешу прив’язується до Next.js build ID. Видалення користувацьких даних залишає встановлену оболонку застосунку.

Історичні ряди завантажуються окремо при відкритті відповідного графіка. Повний історичний snapshot не серіалізується у кожну SSR-сторінку або відповідь `/api/market`. Для WebKit офлайн-перевірка використовує недоступність окремого proxy origin через відомий дефект емулятора `setOffline`: https://github.com/microsoft/playwright/issues/42775.
