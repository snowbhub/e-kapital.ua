Кожен показник має source URL, retrievedAt, effectiveDate, dataType, freshness та basis дати. Якщо емітент не вказує дату конкретного поточного показника, використовується дата отримання з позначкою `retrieved`, а не вигадана дата публікації.

Місячний дивідендний XLSX дає прибуток на сертифікат за звітний місяць. `dateBasis: period` означає період, не підтверджену дату банківської виплати. Ці записи не використовуються для точного XIRR.

## Відмови

Jobs працюють незалежно, валідація до заміни. Помилка одного джерела зберігає його останній валідний snapshot. Стан / остання успішна перевірка / помилка доступні на `/data-sources`. Неповна історія не доповнюється штучно.

Локальне середовище розробки отримувало HTTP 403 від НБУ. GitHub runner успішно отримав поточні курси, 186 випусків із графіками та по 6123 історичних спостереження для USD/EUR/XAU/XAG. bonds.gov.ua у GitHub runner відповів HTTP 403: збережено останню перевірену таблицю. Доступність перевіряється окремо для кожного джерела та середовища.

GitHub workflow `Official data snapshots` запускається щодня о 06:30 UTC і вручну через workflow_dispatch. Після збереження валідних даних workflow повідомляє degraded health як помилку — це не знищує last-known-good значення.

Зміни data layer, ingestion script, workflow або dependency manifest / lockfile також запускають синхронізацію. Це дозволяє повторно перевірити джерела після виправлення залежностей.

Runtime-кеш НБУ зберігає час фактичного запиту разом із результатом на 24 години. Повторне відкриття `/api/market` не змінює `lastSuccess` або `lastAttempt`. Помилка запиту відображається в health; попередні перевірені курси та час останнього успіху зберігаються. Неповний або дубльований набір USD/EUR/XAU/XAG відхиляється до заміни snapshot.

## Завантаження історії

Історія в snapshot зберігається як `[date,value]` та спільна метаінформація джерела для кожного ряду. Reader підтримує попередній формат із metadata на кожному спостереженні. `/api/market` не віддає історію; `/api/history?asset=usd&from=YYYY-MM-DD&to=YYYY-MM-DD` повертає тільки запитаний публічний ряд і metadata. Це не містить сум або параметрів особистого портфеля.
