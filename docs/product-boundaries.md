# Межі поточної реалізації

Застосунок придатний для тестування особистого бюджету, резерву, цілей, ручного обліку капіталу та гіпотетичних сценаріїв. Це не гарантія дохідності й не персональна інвестиційна рекомендація.

## Свідомі обмеження

- Немає банківських інтеграцій, реєстрації, cloud sync або платіжної функції; всі особисті дані на пристрої. Зашифрований backup переносить профіль між пристроями.
- Дані НБУ та точні ОВДП-графіки залежать від доступності офіційного API. Порожній графік не перетворюється на розрахований із ставки купон.
- Повна історія загальної дохідності фонду потребує підтверджених NAV та виплат. Місячний звіт про прибуток на сертифікат не визначає точну дату платежу. Portfolio replay не використовує NAV-only ряд як повну дохідність фонду.
- Сталі користувацькі ставки — сценарії. Немає економічних, валютних або AI-прогнозів, оцінки кредитоспроможності чи автоматичного підбору портфеля.
- Партнерські URL не активні. Каталог містить офіційні посилання і прозорий affiliate disclosure. Нову партнерську програму слід активувати тільки після перевірки умов і вимог розкриття.
- Аналітика не встановлена. Якщо її додавати, спочатку потрібні згода, мінімальний набір подій та виключення фінансових сум / ідентифікаторів / backup.
- Розрахунок єОселі не перевіряє весь юридичний перелік вимог до категорії, сім’ї, площі, віку житла та рішення банку. У UI є посилання на офіційні умови.

## Перед ширшим запуском

Перевірити live source health, всі GitHub quality checks, Safari на реальному iPhone (emulation не замінює пристрій), умови банків / емітентів та актуальність юридичних текстів. Не називати ці перевірки завершеними до підтвердження.
